# ADR-001：POC 技術選型

- **Context**：2014 MBP（雙核、無 GPU、16GB）、Docker 4.12，需 3~5 分鐘離線 live demo；重點是 Agent loop 與軟硬整合，不是模型訓練。
- **Options**：(a) 本地 LLM + LGTM 堆疊；(b) 雲端 LLM + 完整可觀測性堆疊；(c) Mock/雲端可切換 LLM + SQLite，皆經 Port/Adapter。
- **Decision**：選 (c)。離線用決定性 Mock LLM，有網路用 Claude/OpenAI/OpenRouter；logs/metrics/traces、issue、版本、知識庫皆用 SQLite（FTS5 trigram）；不自建模型。
- **Consequences**：Demo 穩定可重現；Mock 的決策是規則，簡報須明講。正式版替換 `ObservabilityPort`（Loki/Prometheus/Tempo）、`LLMProvider`（vLLM/Ollama）、`KnowledgePort`（向量庫）、`VersionStore`（Git/設定中心）。
- **版本策略**：版本採 append-only，rollback 等於新增一版（內容等於目標版），因此 rollback 本身也能被 rollback；內容雜湊相同不新增版本；快照只存 `${SECRET:name}` 引用。
- **已知限制**：快照為整份設定，rollback 會連同上一版之後的無關變更一併還原；正式版可改分區版本。
